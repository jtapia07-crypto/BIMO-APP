# Arquitectura
Frontend estático, HTML semántico, CSS separado y ES Modules. No servicios externos ni código inline. Los diálogos de módulos futuros no simulan servicios. Datos curriculares independientes en data/malla.json, sin modificar el borrador. Preferencia de tema local; el modo demo se controla por URL y no almacena progreso. Sin autenticación, backend ni service worker en esta revisión.
